# Jobs to be done

## Core job

> When a broker submission lands in our inbox, I want to know within minutes whether it is complete, genuine and inside our credit box, so I can make a confident offer before another funder does.

## Job map (underwriter)

| Step | Today (hypothesis) | On the desk |
| --- | --- | --- |
| Notice | Watch a shared inbox; first-come or ad hoc | Queue sorted oldest-first with SLA countdown and flag count |
| Sort | Open each attachment, rename, guess type | Auto-classified with confidence; unknowns highlighted |
| Ask for missing | Discover gaps half-way through | Completeness on arrival, naming the missing month or document |
| Extract | Re-type figures into a sheet or CRM | Fields pre-filled, each with source chips |
| Scrub | Re-add balances, count NSFs, eyeball deposits, compare names | 13 checks run as code; only flags need attention |
| Apply policy | Mental checklist of the credit box | Explicit rules with pass/fail and the reason |
| Decide | Write a note somewhere | Confirm/override each flag with rationale; choose outcome |
| Hand off | Copy into the CRM | One CRM-style package, JSON/CSV |
| Defend later | Reconstruct from email | Exportable audit trail |

## Related jobs

- **Underwriting lead:** "Show me which files are about to breach SLA and which rules my team overrides most, so I can coach or tune the rules."
- **ISO relations:** "Tell me exactly what to ask the broker for, the first time."
- **Compliance:** "Show me who decided what, when, on which evidence."

## Emotional and social jobs

- Feel confident nothing was missed; not be the person who funded a doctored statement.
- Look fast and professional to brokers, who route more deals to funders that respond first.

## Hiring criteria (what would make an underwriter trust it)

1. I can see where every number came from in one click.
2. It tells me when it does not know, instead of guessing.
3. I can overrule it, and my reason is kept.
4. It is right on the boring cases so I can spend time on the hard ones.
